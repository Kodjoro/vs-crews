VS-Crews Changelog

Version: alpha1 (2025-12-27)

Highlights
- Crew persistence: crews and memberships now persist across restarts using world SavedData.
- Server-scoped config: authoritative, per-world settings saved under serverconfig.
- Privacy & protection: non-members cannot see which crew owns a helm; configurable use/break rules.

New Features
- Offline name cache: stores last known player names for readable info and offline member resolution.
- Tab completion: Brigadier suggestions for crew names and player names (online + cached offline).
- Commands:
  - /vscrew create <name>: create a crew (case-insensitive unique names).
  - /vscrew add <crew> <player>: add members; resolves online name, UUID, or cached name.
  - /vscrew remove <crew> <player>: remove members; same resolution as add; cannot remove owner.
  - /vscrew info [crew]: show owner & members (names). With one-crew rule, no-arg form shows your crew.
  - /vscrew list: list crews with member counts.
  - /vscrew delete [crew]: owner-only delete; with one-crew rule, no-arg deletes your owned crew.
  - /vscrew leave [crew]: non-owners can leave; with one-crew rule, no-arg leaves your current crew.

Config (server-side)
- onlyOneCrewPerPlayer (default: true)
  - Blocks creating a second crew if the player already owns or is a member.
  - Enables no-arg forms for info/delete/leave.
- helmWithoutCrewUsableByEveryone (default: false)
  - If true: helms placed by players not in a crew (or with missing crew reference) are usable by everyone.
  - If false: only the placer can use such helms.
- allowNonCrewBreakHelm (default: false)
  - If true: non-members can break helms.
  - If false: only crew members (or owner for no-crew helms) can break.
- allowNonOwnerManageMembers (default: false)
  - If true: any crew member can add/remove members.
  - If false: only the owner can.

Behavior Changes
- Helm interaction & breaks:
  - Crew-protected helms: members allowed; non-members denied without revealing crew names.
  - No crew or missing crew: behavior follows helmWithoutCrewUsableByEveryone and allowNonCrewBreakHelm.
- Helm placement: stores placer UUID and crew name (if any) on the TileEntity NBT.
- Delete crew: helms referencing deleted crews behave as no-crew per config.

Persistence
- Crews, owners, and members saved in world SavedData.
- Name cache saved and refreshed on player login.

Quality of Life
- Clear command feedback (duplicate name, already in a crew, permissions, not found).
- Case-insensitive unique crew names; trim whitespace.

Notes
- SERVER config is authoritative and stored per world (serverconfig). Clients do not need matching configs.
- Restart the server after changing server config values to apply them.
